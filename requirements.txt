# programa, .venv, y no en el Python del equipo, con el pip del equipo:

#   python -m pip --python .venv\Scripts\python.exe install --require-hashes --only-binary=:all: -r requirements.txt
#
# Cada paquete va con su version fija (las que corren en el equipo de desarrollo) y con el sha256 de cada una de
# sus ruedas para Windows, leidos de PyPI el 2026-10-26. pip no instala un archivo cuyo hash no este aca: lo que
# baje tiene que ser byte a byte lo que PyPI publico. Estan los paquetes que usa el programa y los que piden ellos
# (pip exige todos en este modo). Para subir una version se resuelve de nuevo en un venv sin paquetes y se leen
# los hashes de PyPI (CICLO-entorno-propio.md).
#
# Cubre Python 3.11 a 3.14 en Windows de 64 bits (win_amd64). No cubre Python 3.15, ni Windows de 32 bits, ni
# ARM: greenlet 3.3.1 no publica ruedas para ellos, y pip no instala nada en ese modo. Ahi preparar_entorno.py
# abre el programa con el Python del equipo si ya tiene las librerias, y si no, lo dice.
